# etelcastro.github.io

Portafolio de **Etel Castro**, desarrolladora full stack: https://etelcastro.github.io

Sitio estático (HTML, CSS y un poco de JavaScript, sin frameworks) publicado con GitHub Pages.
Modo claro y oscuro, adaptado a celular, accesible con teclado y lector de pantalla.

- `index.html`: el contenido.
- `styles.css`: el diseño (colores en variables, claro y oscuro).
- `main.js`: cambio de tema y animaciones al bajar.
- `img/`: capturas de los proyectos en WebP.

Para verlo en local:

```bash
py -m http.server 8000
```

y abrir http://localhost:8000.
